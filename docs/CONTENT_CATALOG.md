## Reproducible audit and maintenance

Run `python scripts/audit-content.py` after content changes. `docs/content-completion-audit.json` records missing step numbers for every catalog entry; `lib/catalog-coverage.json` supplies the shipped screen map. The staff-only readiness endpoint instead derives current gaps from the actual saved database and supports refresh, filters and access to every matching task.

Native image proof (route, time, capture mode and SHA-256) is in `docs/evidence/`. `reviewed-forms.json` pins the 21 final blank forms. Each report image has a separate proof record and exact article mapping. Historical source paths and original hashes remain in `lib/screenshot-assets.json`. No fabricated UI images are included.

Editorial source review and a screenshot do not certify every branch policy, calculation, role, transaction save or report result. Keep the bounded scope and warnings when reviewing for publication. No current-image attachment changes the publication state or verification date automatically.
